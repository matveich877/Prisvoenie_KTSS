# Присвоение КТСС — автономный сервис

Сервис подготовки документов на присвоение квалификационной категории судьи (приказ Минспорта РФ от 24.01.2024 № 50).

## Состав
- `index.html` — входная точка (загрузчик приложения);
- `asm/` — упакованное приложение (6 частей, редактировать только через пересборку);
- `admin.html` — админ-панель (генерация ключей);
- `admin_asm/` — упакованная админ-панель (9 частей).

## Установка
1. Залейте СОДЕРЖИМОЕ этой папки в корень сайта (или любую подпапку — все пути относительные) на любом статическом хостинге: reg.ru, GitHub Pages, Netlify и т.п.
2. Сервис доступен по адресу: `https://ваш-домен/` (или `https://ваш-домен/папка/`).
3. Админ-панель: `https://ваш-домен/admin.html`. Пароль админки задаётся хэшем в admin_asm (см. инструкцию по смене пароля из прошлой поставки).

## Что нового (12.11.2026, вечер)
- Приветственный экран при первом входе: описание пользы сервиса → «Далее» → 6 шагов работы → «Начать работу». Показывается один раз; повторно — кнопка «📖 Инструкция» в шапке.
- Из письма с ключом убрана подпись «С уважением, Судейский комитет».
- Турниры вводятся только в «Базу турниров»; «Автоподбор по КТ» подтягивает их в документ по требованиям приказа № 50.

## Требования
Статический хостинг с HTTPS. PHP/база данных не нужны. Совместим с GitHub Pages (файл `.nojekyll` при необходимости добавьте в корень).
