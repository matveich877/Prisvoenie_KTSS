# 📋 Генератор документов для спортивных судей (каратэ)

Веб-приложение для автоматического заполнения документов на присвоение квалификационных категорий спортивных судей по виду спорта "каратэ".

## 🚀 Деплой на GitHub Pages

### Шаг 1: Создание репозитория
1. Создайте новый публичный репозиторий на GitHub
2. Загрузите 3 файла: `index.html`, `admin.html`, `README.md`

### Шаг 2: Включение GitHub Pages
1. Перейдите в **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. Save

### Шаг 3: Доступ
- Основное приложение: `https://[username].github.io/[repo]/`
- Админка: `https://[username].github.io/[repo]/admin.html`

## 🔐 Админка

**Тестовый пароль:** `admin123`

⚠️ **Обязательно смените пароль** при первом входе!

### Возможности админки:
- Генерация ключей 4 типов:
  - **Тестовый** — 10 выгрузок
  - **Премиум** — 100 выгрузок
  - **Универсальный** — безлимит
  - **Custom** — свои настройки
- Привязка ключа к конкретному email
- Просмотр всех активаций (кто, когда, какой email)
- Экспорт статистики в CSV
- Удаление/отзыв ключей

## 🔒 Система защиты

### 1. Привязка к email
При активации пользователь вводит email. Ключ привязывается к этому email и не может быть использован другим человеком.

### 2. Привязка к устройству (fingerprint)
Генерируется уникальный ID устройства на основе:
- User Agent
- Разрешения экрана
- Языка браузера
- Количества ядер CPU

Ключ работает только на том устройстве, где был активирован.

### 3. Ограничение по количеству устройств
Каждый ключ имеет параметр `maxDevices`:
- `1` — только одно устройство
- `3` — до трёх устройств
- `-1` — без ограничений

### 4. Срок действия
Каждый ключ имеет дату истечения. После этой даты ключ перестаёт работать.

## 🎯 Тестовые ключи

Для тестирования используйте:
- **Универсальный:** `KARATE-UNIVERSAL-2024-MASTER`
- **Тестовые:** `KARATE-TEST-001`, `KARATE-TEST-002`, `KARATE-TEST-003`
- **Премиум:** `KARATE-PREMIUM-2024`

## 📋 Функционал приложения

- Автоматическая проверка КТ каратэ
- Матрица допустимых должностей по категории судьи и статусу соревнования
- Генерация 4 документов (Word/PDF) в альбомной ориентации A4:
  1. Представление (Приложение №1)
  2. Карточка учёта — шапка + история категорий
  3. Карточка учёта — теоретическая подготовка
  4. Карточка учёта — практика судейства
- Сохранение/загрузка данных в браузере
- Пример заполнения (данные Матвеева К.О.)
